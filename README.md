# Projeto de Testes de API - JSONPlaceholder

Este repositório contém uma coleção de testes automatizados de API desenvolvidos no Postman para o endpoint **/posts** do JSONPlaceholder.

O que foi testado:
- Validação de Status Code (200 OK).
- Teste de Contrato (JSON Schema): Validação estrutural dos campos obrigatórios (userId, id, title, body) e seus respectivos tipos de dados para garantir a integridade do contrato da API.
